# MJV Masonry & Contracting Website

## Project Overview

This project aims to design, build, and deploy a professional website and automation system for **MJV Masonry & Contracting**.

The website will help potential customers:

* Learn about masonry services
* View project portfolios
* Request quotes
* Book consultations
* Contact Marty

The project also includes automation workflows to support:

* Lead capture
* Quote requests
* Appointment scheduling
* Lead tracking
* Customer communications
